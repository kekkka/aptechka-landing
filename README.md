# Аптечка — утверждённый лендинг

Статический адаптивный лендинг без сборки и внешнего JS. Контент согласован: оффер №1, забота + технологии, 12 тематических блоков.

## Запуск

Откройте `index.html` или запустите `python3 -m http.server 8000` из этой папки и перейдите на http://localhost:8000.

## Публикация через GitHub Pages

1. Создайте **отдельный репозиторий** `aptechka-landing` (не заменяйте существующий `aptechka-beta`).
2. Загрузите **содержимое** этой папки в корень репозитория, включая `index.html`, `styles.css`, `script.js`, `assets/` и `.nojekyll`.
3. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Адрес сайта: `https://<username>.github.io/aptechka-landing/`.

Можно использовать любой другой статический хостинг. Абсолютных путей к ресурсам нет.

## Заявки и ограничения

- Пока нет API или CRM, кнопка формы **не делает вид, что отправляет заявку**: копирует текст сообщения в буфер и открывает Telegram `@kkkkkeka`; отправить скопированное сообщение должен посетитель. Если браузер запрещает буфер, текст появляется в поле для ручного копирования.
- Перед запуском подтвердить согласие на размещение публичного телефона и Telegram из презентации.
- Перед интеграцией серверной формы понадобится реальная политика конфиденциальности, законное основание для обработки данных, защита и настройка хранения. Текущий блок `#privacy` объясняет работу *только статической страницы*.
- Изображения извлечены из предоставленной презентации (демонстрационные экраны). В них присутствует пример пациента; не публикуйте содержащие личные данные изображения без согласия. Заменить обрезки на чистые экспортированные UI-скриншоты рекомендуется после утверждения дизайна.
- Google Fonts загружается извне; при необходимости полностью автономной работы замените `@import` в `styles.css` на системные шрифты.
- Прототип: https://kekkka.github.io/aptechka-beta/.

## Структура

`index.html` — разметка и контент; `styles.css` — адаптивный дизайн; `script.js` — меню и подготовка заявки; `assets/` — скриншоты из презентации.
